# LESSON-6 — Защищённые маршруты и авторизация

Ветка: `lesson-6`

## Запуск

```bash
npm ci
npm run dev     # http://localhost:5173
npm run build
npm run lint
```

Маршруты: `/login` — вход, `/profile` — закрытая страница, `/public` — открытая.
Ссылки на них есть в шапке страницы задач.

## Что сделал

Авторизация через контекст, маршруты закрываются по нему же.

- `features/authRouting/AuthContext.ts` — контекст и ключ хранилища
- `features/authRouting/AuthProvider.tsx` — состояние, вход, выход, восстановление сессии
- `features/authRouting/useAuth.ts` — доступ к контексту
- `features/authRouting/ProtectedRoute.tsx` — охрана маршрутов, `<Outlet />`
- `features/authRouting/api.ts` — `POST /auth/login` и `GET /users/me`
- `pages/login`, `pages/profile`, `pages/public` — страницы
- `app/router.tsx` — `/profile` вложен в `ProtectedRoute`

## Адрес API

Запросы идут на `https://api.v2.react-learning.ru` — эндпоинты лежат в корне,
без префикса `/api` (по нему отдаётся Swagger с документацией).

```
POST /auth/login   { email, password }  → { user, accessToken }
GET  /users/me     Bearer-токен         → профиль
```

## Что понял по ходу

- `ProtectedRoute` смотрит только в контекст — `localStorage` в нём не упоминается,
  иначе выход из аккаунта не вызвал бы перерисовку и закрытая страница осталась бы на экране
- без флага загрузки после F5 профиль выбрасывал бы на `/login`: токен уже есть,
  а кто пользователь — ещё неизвестно
- 401 и сетевую ошибку надо различать: при 401 токен мёртв и сессию закрываем,
  при обрыве связи — оставляем, иначе блип сети разлогинивает
- `AbortController` в эффекте нужен из-за StrictMode: он монтирует дважды,
  и без отмены два ответа гонятся за один стейт
