Ветка: `lesson-4`

```bash
npm ci

npm run build
npm run lint
```

Форма на `/register`, ссылка на неё — сверху страницы задач.

## Что сделал

Взял React Hook Form и zod. Форма регистрации на четыре поля, блок социальных ссылок,
который можно расширять и сокращать, и мини-форма подписки в два шага на `useActionState`.

Валидация описана одной схемой в `features/registerForm/model/schema.ts`, тип значений
выводится оттуда же через `z.infer`.

## Что понял по ходу

- `path` в `refine` закрепляет ошибку за своим полем, без него она висит на всей форме
- `useFieldArray` не работает с массивом строк — нужен массив объектов
- `key` строки берётся из `field.id`, с индексом значения съезжают при удалении
- `useActionState` хранит состояние сам, под шаги мастера `useState` не нужен
- чтобы `pending` было видно, в экшене стоит пауза
